help Pull Requestの送り方
1 タブごとに作品情報を入力すると、右側に登録する作品すべてのJSONが自動生成されます。
2 「JSONをコピー」でデータをクリップボードにコピーします。
3 「GitHubで編集」を開き、リポジトリの docs/data/works.json の works 配列へ作品オブジェクトを追加し、Pull Requestを送ってください。

1作品の場合は作品オブジェクト、2作品以上の場合は作品オブジェクトの配列を出力します。複数時は配列内の各オブジェクトを追加します。

GitHubで編集 を開いてから、コピーした作品オブジェクト（複数時は配列内の各オブジェクト）を works 配列の末尾に追加して Pull Request を作成してください。

コピーしたデータは docs/data/works.json に追加されます。
